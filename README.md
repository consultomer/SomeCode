# SomeCode

A collection of early programming exercises and university coursework, kept as
a record of where I started. These are learning snippets, not production code.

## Contents

| Folder | What's inside |
| --- | --- |
| `Python/` | Small console scripts, e.g. an age-to-decades calculator |
| `PHP/` | PHP basics: syntax, variables, and user-defined functions |
| `Web/` | Static HTML/CSS pages |
| `University Code/` | C programs (CS403) and HTML/CSS assignments (CS202) |

## Running

- **Python:** `python3 Python/Calculator.py`
- **PHP:** `php PHP/Basic.php`, or serve the folder with `php -S localhost:8000`
- **C:** `gcc "University Code/some.c" -o some && ./some`
- **Web:** open any `.html` file in a browser
